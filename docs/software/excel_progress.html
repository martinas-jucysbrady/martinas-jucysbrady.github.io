1. Formulas & Functions

Excel formulas are the foundation of any spreadsheet analysis. The most important distinction is understanding when to use relative vs absolute references, and how to combine functions to build powerful, reusable logic.

Key functions

Function Purpose
SUM, AVERAGE, COUNT Basic aggregation
IF, IFS, NESTED IF Conditional logic
VLOOKUP, HLOOKUP, INDEX/MATCH Data lookup
SUMIF, COUNTIF, AVERAGEIF Conditional aggregation
LEFT, RIGHT, MID, TEXT Text manipulation
TODAY, DATE, DATEDIF Date functions

A core formula pattern I use frequently is combining INDEX and MATCH as a more flexible alternative to VLOOKUP. The logic can be expressed as:

\[\text{Result} = \text{INDEX}(\text{return\_range},\ \text{MATCH}(\text{lookup\_value},\ \text{lookup\_range},\ 0))\]

Unlike VLOOKUP, this works in any direction and does not break when columns are inserted.1

2. Data Manipulation & Formatting

Clean, well-structured data is a prerequisite for any meaningful analysis. Excel provides a range of tools for reshaping and cleaning data before analysis begins.

Key techniques

TipBest practices I follow
  • Always freeze the header row and use Format as Table to enable structured references
  • Use Text to Columns and Flash Fill for rapid data cleaning
  • Name key ranges to make formulas readable (=SUM(Sales) rather than =SUM(B2:B200))
  • Use TRIM and CLEAN to remove invisible characters from imported data
Show code 
raw = pd.DataFrame({
    'ID':      [1, 2, 2, 3, 4, 5, 5, 6],
    'Name':    ['  Alice', 'Bob', 'Bob', 'Charlie ', 'Diana', None, 'Eve', 'Frank'],
    'Revenue': [1200, 850, 850, None, 2100, 760, 760, 980],
    'Region':  ['North', 'South', 'South', 'East', None, 'West', 'West', 'North'],
})

steps = ['Raw data', 'Remove duplicates', 'Fill missing', 'Trim whitespace', 'Clean data']
issues = [
    raw.duplicated().sum() + raw.isnull().sum().sum(),
    raw.drop_duplicates().isnull().sum().sum(),
    raw.drop_duplicates().fillna({'Revenue': raw['Revenue'].median(), 'Region': 'Unknown'}).isnull().sum().sum(),
    0, 0
]

fig, ax = plt.subplots(figsize=(8, 3.5))
colors = ['#C00000' if v > 0 else '#2E75B6' for v in issues]
bars = ax.bar(steps, issues, color=colors)
ax.bar_label(bars, fmt='%d issues', padding=3, fontsize=9)
ax.set_ylabel('Remaining Issues')
ax.set_title('Data Cleaning Pipeline — Issues Resolved at Each Step', fontsize=11)
plt.xticks(rotation=10)
plt.tight_layout()

4. Charts & Dashboards

A well-designed dashboard communicates the key message at a glance. In Excel, I build dashboards using a combination of pivot charts, slicers, dynamic named ranges, and careful layout design.

Dashboard design principles I follow

TipWhat makes a good Excel dashboard
  • One clear message per chart — avoid chart overload
  • Consistent colour palette aligned with the brand or report theme
  • Slicers and dropdowns to let the reader filter without touching the data
  • Freeze panes and locked cells to protect the model
  • Separate data, calculations and presentation into distinct sheets

5. Finance Functions & Statistical Analysis

I applied Excel’s financial and statistical functions most intensively during the investment portfolio project in third year, using them to calculate Sharpe ratios, expected returns and standard deviations across a 32-asset portfolio.

Key financial functions

Function Formula Use
NPV \(NPV = \sum_{t=1}^{n} \frac{CF_t}{(1+r)^t}\) Net present value
IRR Solve for \(r\): \(\sum \frac{CF_t}{(1+r)^t} = 0\) Internal rate of return
PMT \(PMT = \frac{P \cdot r}{1-(1+r)^{-n}}\) Loan/annuity payment
FV \(FV = PV \cdot (1+r)^n\) Future value
STDEV \(\sigma = \sqrt{\frac{\sum(x_i - \bar{x})^2}{n-1}}\) Standard deviation

The Sharpe ratio is the key metric I used in the portfolio project to compare risk-adjusted returns:

\[S = \frac{R_p - R_f}{\sigma_p}\]

Where \(R_p\) is the portfolio return, \(R_f\) is the risk-free rate, and \(\sigma_p\) is the portfolio standard deviation. A Sharpe ratio above 1.0 is generally considered good.2

6. Solver & Optimisation

Excel’s Solver add-in was central to my investment portfolio project. I used it to maximise the Sharpe ratio subject to constraints on individual asset weights, sector exposure and total portfolio weight.

WarningA key lesson from using Solver

Unconstrained Solver optimisation almost always concentrates all weight in one or two high-volatility assets. In practice, you need to impose realistic upper bounds on each asset and sector, and combine the quantitative output with qualitative judgement about what a sensible portfolio actually looks like.

The optimisation problem I set up was:

\[\max_{w} \quad S(w) = \frac{w^T \mu - R_f}{\sqrt{w^T \Sigma w}}\]

Subject to:

\[\sum_i w_i = 1, \quad 0 \leq w_i \leq w_{max}, \quad \sum_{i \in \text{sector}} w_i \leq s_{max}\]

Where \(w\) is the vector of portfolio weights, \(\mu\) is the vector of expected returns, and \(\Sigma\) is the covariance matrix.

Show code 
np.random.seed(42)
n_portfolios = 3000
returns_range = []
risks_range   = []
sharpes_range = []

mean_returns = np.array([0.15, 0.12, 0.08, 0.18, 0.06])
cov_matrix   = np.array([
    [0.04, 0.01, 0.005, 0.015, 0.002],
    [0.01, 0.03, 0.004, 0.012, 0.001],
    [0.005,0.004,0.01,  0.003, 0.001],
    [0.015,0.012,0.003, 0.05,  0.002],
    [0.002,0.001,0.001, 0.002, 0.005],
])
rf = 0.03

for _ in range(n_portfolios):
    w = np.random.dirichlet(np.ones(5))
    r = np.dot(w, mean_returns)
    s = np.sqrt(np.dot(w.T, np.dot(cov_matrix, w)))
    returns_range.append(r)
    risks_range.append(s)
    sharpes_range.append((r - rf) / s)

fig = px.scatter(
    x=risks_range, y=returns_range, color=sharpes_range,
    color_continuous_scale='Blues',
    labels=dict(x='Risk (Std Dev)', y='Expected Return', color='Sharpe Ratio'),
    title='Efficient Frontier — Risk vs Return (3,000 random portfolios)',
)
fig.update_traces(marker=dict(size=4, opacity=0.6))
fig.update_layout(height=420)
fig.show()
